# reed-thesis-template-typst

This is an unofficial Typst template for writing a Reed College senior thesis developed by Reed College students and alums. The output should be nearly identical to the official LaTeX template; it has been successfully used for multiple theses.

## Usage

```sh
typst init @preview/rcnf-reed-thesis:1.1.0
```

## Local setup

For development, or to use this before it is published on Typst Universe, follow [the instructions to install a local package](https://github.com/typst/packages/blob/main/README.md#local-packages).

Then, you can run:

```sh
typst init @local/rcnf-reed-thesis
```
